01. Tentang Saya

Saya I Komang Pradnya Wiryatama, developer Indonesia yang fokus pada pengembangan aplikasi web full-stack. Di komunitas Central Saga saya terlibat membangun berbagai sistem informasi nyata: e-commerce, kepegawaian, inventori, manajemen kontrak klien, hingga sistem monitoring infrastruktur.

Saya terbiasa mengerjakan proyek dari sisi API & basis data (Laravel + PostgreSQL + Redis) sampai antarmuka pengguna (Next.js/React + TypeScript), termasuk deployment dan automasi dengan container.

  • 📍 Domisili: Indonesia
  • 💼 Komunitas: Central Saga (github.com/Central-Saga)
  • 🌱 Fokus: Laravel · Next.js · PostgreSQL · Redis · Podman
